# ⭐ Lecture 1 — Representação, Vetores e Classificadores Lineares

## 1. O que esta lecture adiciona ao modelo
Lecture 1 estabelece a fundação:

- exemplos são vetores  
- rótulos são valores discretos  
- classificadores são funções  
- hiperplanos separam classes  

A primeira equação do curso aparece aqui:

$$
h(x) = \text{sign}(w \cdot x + b)
$$

Ela define o modelo linear.

## 2. Qual problema ela resolve
Ela responde:

- Como representar dados?  
- Como definir uma regra de decisão?  
- Como medir erro?  

O erro de treinamento aparece:

$$
E_n(h) = \frac{1}{n}\sum_{i=1}^n [h(x_i) \neq y_i]
$$

## 3. Conexão com a lecture anterior
Lecture 1 abre o curso — não há anterior.

## 4. Como prepara a próxima lecture
Lecture 2 vai responder:

> “Como encontrar $w$ e $b$ na prática?”

## 5. Narrativa contínua
Lecture 1 transforma o mundo real em matemática.  
Cada filme, imagem, molécula ou review vira um vetor:

$$
x = (x_1, x_2, \dots, x_d)
$$

Cada vetor é um ponto em $\mathbb{R}^d$.  
Cada classificador é um hiperplano que divide o espaço.

```
      + classe +1
      |
      |      w·x + b = 0
------+-------------------------
      |
      |      classe -1
```

A lecture termina com uma pergunta inevitável:

> “Se classificadores lineares são tão importantes, como aprendê‑los?”

# ⭐ Lecture 2 — Perceptron e Separação Linear

## 1. O que esta lecture adiciona ao modelo
Lecture 2 introduz:

- separabilidade linear  
- fronteiras com e sem deslocamento  
- o primeiro algoritmo de aprendizado: **Perceptron**

A condição de separabilidade aparece:

$$
y^{(i)}(w \cdot x^{(i)} + b) > 0
$$

E a atualização do perceptron:

$$
w \leftarrow w + y^{(i)} x^{(i)}
$$

$$
b \leftarrow b + y^{(i)}
$$

## 2. Qual problema ela resolve
Lecture 1 apresentou o modelo.  
Lecture 2 apresenta o **algoritmo**.

## 3. Conexão com a lecture anterior
Lecture 1 definiu hiperplanos.  
Lecture 2 mostra como movê‑los.

## 4. Como prepara a próxima lecture
O perceptron só converge se os dados forem separáveis.  
Isso cria a pergunta:

> “E quando não são?”

Lecture 3 responde isso com margem e hinge loss.

## 5. Narrativa contínua
Lecture 2 dá vida ao hiperplano.  
Agora ele se move, aprende, reage.

O perceptron tenta satisfazer:

```
Pontos positivos → lado positivo
Pontos negativos → lado negativo
```

Mas quando os dados não são separáveis, o perceptron entra em loop:

```
erro → atualização → erro → atualização → erro → ...
```

Essa limitação abre a porta para Lecture 3.

# ⭐ Lecture 3 — Margem, Distância Geométrica e Perda Hinge

## 1. O que esta lecture adiciona ao modelo
Lecture 3 introduz três pilares:

### ✔ Margem geométrica  
A distância de um ponto ao hiperplano:

$$
d = \frac{|w \cdot x + b|}{\|w\|}
$$

A margem é:

$$
\gamma = \frac{1}{\|w\|}
$$

### ✔ Limites de margem  
As duas retas paralelas:

$$
w \cdot x + b = +1
$$

$$
w \cdot x + b = -1
$$

### ✔ Perda hinge  
A penalização suave:

$$
\ell_{\text{hinge}}(z) = \max(0, 1 - z)
$$

onde:

$$
z = y(w \cdot x + b)
$$

### ✔ Regularização  
Controle da complexidade:

$$
\frac{1}{2}\|w\|^2
$$

## 2. Qual problema ela resolve
Ela resolve o problema deixado pela Lecture 2:

> “Como aprender quando os dados não são separáveis?”

## 3. Conexão com a lecture anterior
Lecture 2 tinha:

- hiperplano  
- atualização por erro  

Lecture 3 adiciona:

- distância  
- margem  
- penalização  
- otimização convexa  

## 4. Como prepara a próxima lecture
Lecture 4 vai responder:

> “Como minimizar a função objetivo?”

## 5. Narrativa contínua
Lecture 3 é onde a geometria se torna otimização.

A distância ponto‑hiperplano aparece:

```
                P
                *
               /|
              / |
             /  | d
------------*---+----------------
```

E com ela, a margem:

$$
\gamma = \frac{1}{\|w\|}
$$

A perda hinge diz:

```
Se z ≥ 1 → custo 0
Se 0 < z < 1 → custo linear
Se z ≤ 0 → erro
```

A função objetivo final é:

$$
J(w,b) =
\frac{1}{n}\sum_{i=1}^n \max(0, 1 - y^{(i)}(w \cdot x^{(i)} + b))
+ \lambda \frac{1}{2}\|w\|^2
$$

Lecture 3 fecha com a pergunta:

> “Como minimizar isso?”

Adendo:
> A menor distância entre o ponto $P$ e a reta $R$

$$d(P, R) = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}} = \frac{|w + x_0 + b|}{\sqrt{\|w\|}} $$

# ⭐ Lecture 4 — Gradiente, SGD e o Papel de λ

## 1. O que esta lecture adiciona ao modelo
Lecture 4 introduz:

- gradiente descendente  
- gradiente descendente estocástico (SGD)  
- interpretação prática de $\lambda$  
- como a solução muda com $\lambda$  

A atualização geral é:

$$
w \leftarrow w - \eta \nabla_w J
$$

Para hinge loss:

- se $y(w \cdot x + b) \ge 1$:

$$
\nabla_w J = \lambda w
$$

- se $y(w \cdot x + b) < 1$:

$$
\nabla_w J = \lambda w - yx
$$

## 2. Qual problema ela resolve
Lecture 3 definiu a função objetivo.  
Lecture 4 ensina a **minimizá‑la**.

## 3. Conexão com a lecture anterior
Lecture 3 → função objetivo  
Lecture 4 → algoritmo para minimizá‑la

## 4. Como prepara a próxima lecture
Lecture 5 introduz:

- dualidade  
- support vectors  
- solução fechada do SVM  

## 5. Narrativa contínua
Lecture 4 transforma a função objetivo em movimento.

O gradiente aponta a direção de maior aumento.  
O algoritmo anda na direção oposta:

```
θ ← θ − η ∇J
```

O SGD aparece como a versão prática:

```
Use apenas um ponto por vez.
Atualize rápido.
Converge bem.
```

O parâmetro λ controla o equilíbrio:

- λ grande → margem grande, modelo simples  
- λ pequeno → margem pequena, modelo complexo  

Lecture 4 fecha com a ponte para Lecture 5:

> “A solução ótima depende apenas de alguns pontos — os support vectors.”

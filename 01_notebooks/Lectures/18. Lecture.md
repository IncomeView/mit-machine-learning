Lecture 18 — Parte 1  
Introdução ao Value Iteration  
=============================

Nesta lecture, avançamos para o algoritmo central que permite **resolver MDPs** quando:

- conhecemos os estados,  
- conhecemos as ações,  
- conhecemos as transições,  
- conhecemos as recompensas.

O objetivo da Lecture 18 é:

1. Revisar a Equação de Bellman Ótima.  
2. Entender por que Bellman pode ser usado iterativamente.  
3. Introduzir o algoritmo de **Value Iteration**.  
4. Mostrar como calcular $ V^*(s) $.  
5. Demonstrar como extrair a política ótima $ \pi^*(s) $.  
6. Entender por que o algoritmo converge.

---

## 1. Conectando Lecture 17 à Lecture 18

Na Lecture 17 aprendemos:

- o que é uma política,  
- o que é uma função de valor,  
- como Bellman define $ V^*(s) $,  
- como Bellman define $ \pi^*(s) $,  
- como valores são propagados pelo ambiente.

Agora queremos **resolver** o MDP:

> Encontrar $ V^*(s) $ para todos os estados  
> e derivar a política ótima $ \pi^*(s) $.

Para isso, usamos **Value Iteration**.

---

## 2. Relembrando Bellman Optimality

A Equação de Bellman Ótima é:

$$
V^*(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') \, V^*(s') \right]
$$

Essa equação é **recursiva**:

- o valor de um estado depende dos valores dos estados futuros,  
- que dependem dos valores dos estados seguintes,  
- e assim por diante.

Bellman define um sistema de equações acopladas.

---

## 3. O desafio

Bellman nos diz **como** o valor ótimo deve ser, mas não nos diz **como calcular** esse valor.

Resolver Bellman diretamente exigiria:

- montar um sistema de equações,  
- resolver simultaneamente todos os estados,  
- lidar com dependências complexas.

Isso é inviável para ambientes grandes.

---

## 4. A ideia central do Value Iteration

Value Iteration usa Bellman como uma **atualização iterativa**:

1. Começamos com uma estimativa inicial de $ V(s) $.  
2. Aplicamos Bellman repetidamente.  
3. Cada aplicação melhora a estimativa.  
4. Eventualmente, $ V(s) $ converge para $ V^*(s) $.

Essa abordagem é:

- simples,  
- eficiente,  
- escalável,  
- matematicamente garantida.

---

## 5. Atualização de Value Iteration

A atualização é:

$$
V_{k+1}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') \, V_k(s') \right]
$$

onde:

- $ V_k(s) $ é o valor na iteração $ k $,  
- $ V_{k+1}(s) $ é o valor atualizado.

---

## 6. Intuição da atualização

Cada iteração:

- propaga valores dos estados futuros para os estados atuais,  
- melhora a estimativa de $ V(s) $,  
- aproxima o valor ótimo.

É como uma “onda” de valores se espalhando pelo ambiente.

---

## 7. Por que Value Iteration funciona?

Porque:

- Bellman é uma **contração** matemática,  
- o fator $ \gamma $ garante que a influência dos estados futuros diminui,  
- a atualização converge para um **ponto fixo**,  
- esse ponto fixo é exatamente $ V^*(s) $.

---

## 8. Conclusão da Parte 1

Nesta parte entendemos:

- por que Bellman define o valor ótimo,  
- por que precisamos de um algoritmo iterativo,  
- como Value Iteration aplica Bellman repetidamente,  
- como a atualização funciona,  
- por que o algoritmo converge.

Na próxima parte estudaremos:

- o algoritmo completo de Value Iteration,  
- pseudocódigo,  
- critérios de parada,  
- extração da política ótima.

Lecture 18 — Parte 2  
Value Iteration — O Algoritmo Completo  
=============================

Na Parte 1, entendemos a motivação do Value Iteration e revisamos a Equação de Bellman Ótima.  
Agora, nesta parte, apresentamos:

1. O algoritmo completo de Value Iteration.  
2. O pseudocódigo formal.  
3. O critério de parada.  
4. Como extrair a política ótima após a convergência.

---

## 1. Relembrando a atualização de Bellman

A atualização central do Value Iteration é:

$$
V_{k+1}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') \, V_k(s') \right]
$$

Essa equação:

- melhora a estimativa de $ V(s) $ a cada iteração,  
- aproxima o valor ótimo $ V^*(s) $,  
- é aplicada repetidamente até convergir.

---

## 2. Estrutura geral do algoritmo

O algoritmo segue três passos:

1. **Inicialização**  
2. **Atualização iterativa (Bellman)**  
3. **Critério de parada**

---

## 3. Inicialização

Começamos com uma estimativa inicial para todos os estados:

$$
V_0(s) = 0
$$

ou qualquer valor arbitrário.

A escolha não afeta o resultado final, apenas a velocidade de convergência.

---

## 4. Atualização iterativa

Para cada estado $ s $, aplicamos Bellman:

$$
V_{k+1}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') \, V_k(s') \right]
$$

Essa atualização:

- propaga valores dos estados futuros para os estados atuais,  
- melhora a estimativa de $ V(s) $,  
- aproxima o valor ótimo.

---

## 5. Critério de parada

O algoritmo para quando:

$$
\max_s \left| V_{k+1}(s) - V_k(s) \right| < \epsilon
$$

onde:

- $ \epsilon $ é um limite pequeno (ex.: $ 10^{-3} $),  
- garante que a mudança entre iterações é mínima,  
- indica que o valor convergiu.

---

## 6. Pseudocódigo formal (padrão do curso)

```
Inicialize V(s) arbitrariamente
Repita:
    Δ = 0
    Para cada estado s:
        v = V(s)
        V(s) = max_a [ R(s, a) + γ Σ_{s'} T(s, a, s') V(s') ]
        Δ = max(Δ, |v - V(s)|)
Até que Δ < ε
Retorne V(s)
```

Esse pseudocódigo segue exatamente o estilo usado na Lecture 16.

---

## 7. Extraindo a política ótima

Após a convergência de $ V^*(s) $, a política ótima é:

$$
\pi^*(s) = \arg\max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') \, V^*(s') \right]
$$

Ou seja:

> Para cada estado, escolha a ação que maximiza o valor futuro esperado.

---

## 8. Intuição visual

Imagine o grid da Lecture 17:

- O estado com recompensa +1 tem valor alto.  
- O estado com punição −1 tem valor baixo.  
- Estados próximos ao +1 têm valores intermediários.  
- Estados próximos ao −1 têm valores negativos.

Value Iteration:

- começa com todos os valores iguais,  
- aplica Bellman repetidamente,  
- propaga valores dos estados terminais para os demais,  
- converge para $ V^*(s) $,  
- e então extrai a política ótima.

---

## 9. Conclusão da Parte 2

Nesta parte aprendemos:

- o algoritmo completo de Value Iteration,  
- o pseudocódigo formal,  
- o critério de parada,  
- como extrair a política ótima após a convergência.

Na próxima parte estudaremos:

- Propriedades de convergência,  
- Interpretação matemática,  
- Exemplos completos de execução do algoritmo.

Lecture 18 — Parte 3  
Convergência do Value Iteration  
=============================

Nesta parte, estudamos **por que** o algoritmo de Value Iteration funciona.  
A professora explica que a convergência não é apenas empírica — ela é garantida matematicamente.

O objetivo desta parte é entender:

1. Por que Bellman é uma contração.  
2. Por que Value Iteration converge para $ V^*(s) $.  
3. Como interpretar a convergência intuitivamente.  
4. Como isso garante que a política extraída é ótima.

---

## 1. Relembrando a atualização de Value Iteration

A atualização é:

$$
V_{k+1}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') V_k(s') \right]
$$

Essa operação é chamada de **Operador de Bellman Ótimo**, denotado por:

$$
B[V](s)
$$

onde:

$$
B[V](s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') V(s') \right]
$$

Value Iteration aplica esse operador repetidamente:

$$
V_{k+1} = B[V_k]
$$

---

## 2. Propriedade fundamental: Bellman é uma contração

O operador de Bellman é uma **contração** no espaço das funções de valor.

Isso significa que:

$$
\| B[V] - B[U] \|_\infty \le \gamma \| V - U \|_\infty
$$

onde:

- $ \| \cdot \|_\infty $ é a norma máximo,  
- $ 0 < \gamma < 1 $ é o fator de desconto.

### Consequência:

> Cada aplicação de Bellman aproxima $ V $ do valor ótimo $ V^*(s) $.

---

## 3. Teorema da Convergência

O teorema diz:

> Para qualquer função inicial $ V_0 $, a sequência  
> $ V_1, V_2, V_3, \dots $  
> gerada por Value Iteration converge para $ V^*(s) $.

Formalmente:

$$
\lim_{k \to \infty} V_k(s) = V^*(s)
$$

E mais:

$$
\| V_k - V^* \|_\infty \le \gamma^k \| V_0 - V^* \|_\infty
$$

Ou seja:

- a convergência é **exponencial**,  
- quanto menor o $ \gamma $, mais rápida a convergência.

---

## 4. Intuição da convergência

A professora usa a metáfora da “onda de valor”:

- Começamos com valores arbitrários (ex.: zero).  
- Aplicamos Bellman.  
- Os estados terminais irradiam seus valores.  
- Estados vizinhos recebem valores intermediários.  
- A onda se espalha pelo ambiente.  
- A cada iteração, a onda fica mais precisa.  
- Eventualmente, a onda estabiliza.

Essa estabilização é exatamente:

$$
V^*(s)
$$

---

## 5. Por que o fator de desconto $ \gamma $ é essencial?

Sem desconto:

- o operador de Bellman **não** seria uma contração,  
- a convergência **não** seria garantida,  
- o valor poderia divergir.

Com desconto:

- recompensas futuras têm peso menor,  
- a influência dos estados distantes diminui,  
- o operador se torna uma contração,  
- a convergência é garantida.

---

## 6. Convergência da política

Depois que $ V_k(s) $ converge para $ V^*(s) $, a política extraída:

$$
\pi^*(s) = \arg\max_{a} \left[ R(s, a) + \gamma \sum_{s'} T(s, a, s') V^*(s') \right]
$$

é garantidamente **ótima**.

Isso ocorre porque:

- Bellman Optimality define exatamente a política ótima,  
- e Value Iteration converge para a solução de Bellman.

---

## 7. Conclusão da Parte 3

Nesta parte aprendemos:

- por que Bellman é uma contração,  
- por que Value Iteration converge para $ V^*(s) $,  
- como interpretar a convergência intuitivamente,  
- por que o fator de desconto é essencial,  
- por que a política extraída após a convergência é ótima.

Na próxima parte estudaremos:

- exemplos completos de execução do algoritmo,  
- cálculo manual de algumas iterações,  
- visualização da propagação de valores.

Lecture 18 — Parte 4  
Execução do Value Iteration — Exemplo Completo  
=============================

Nesta parte, aplicamos o algoritmo de Value Iteration em um exemplo concreto.  
O objetivo é visualizar:

1. Como os valores começam,  
2. Como Bellman atualiza cada estado,  
3. Como a “onda de valor” se espalha,  
4. Como o algoritmo converge,  
5. Como a política ótima emerge naturalmente.

---

## 1. O ambiente do exemplo

Usaremos o grid clássico da Lecture 17:

- Um estado terminal com recompensa **+1**,  
- Um estado terminal com recompensa **−1**,  
- Estados intermediários com recompensa **0**,  
- Movimentos com transições probabilísticas (ex.: 80% na direção desejada, 10% para cada lado).

Representação simplificada:

```
[  ] [   ] [  ] [+1]
[  ] [ X ] [  ] [  ]
[  ] [   ] [  ] [-1]
```

Onde:

- `[X]` é uma parede,  
- `[+1]` é o estado terminal positivo,  
- `[-1]` é o estado terminal negativo.

---

## 2. Inicialização

Começamos com:

$$
V_0(s) = 0
$$

para todos os estados não terminais.

E:

- $ V(+1) = +1 $  
- $ V(-1) = -1 $

---

## 3. Primeira iteração — $ V_1 $

Aplicamos Bellman:

$$
V_1(s) = \max_{a} \left[ R(s,a) + \gamma \sum_{s'} T(s,a,s') V_0(s') \right]
$$

Como todos os valores iniciais são zero:

- estados vizinhos do +1 recebem valor positivo,  
- estados vizinhos do −1 recebem valor negativo.

Exemplo:

Se $ \gamma = 0.9 $:

$$
V_1(s_{\text{vizinho do +1}}) \approx 0.9 \cdot 1 = 0.9
$$

$$
V_1(s_{\text{vizinho do -1}}) \approx 0.9 \cdot (-1) = -0.9
$$

---

## 4. Segunda iteração — $ V_2 $

Agora os valores começam a se espalhar:

- estados a dois passos do +1 recebem valores como $ 0.9^2 = 0.81 $,  
- estados a dois passos do −1 recebem valores como $ -0.9^2 = -0.81 $.

A “onda de valor” avança:

```
0.81   0.90   1.00
0.72    X     0.90
0.65   0.72  -0.90
```

---

## 5. Iterações seguintes — $ V_3, V_4, \dots $

A cada iteração:

- valores ficam mais precisos,  
- diferenças entre estados diminuem,  
- o grid inteiro converge para $ V^*(s) $.

Eventualmente, os valores estabilizam:

```
0.93   0.97   1.00
0.85    X     0.97
0.78   0.85  -0.97
```

Esses valores são **ótimos**.

---

## 6. Extração da política ótima

Depois que $ V^*(s) $ converge, extraímos a política:

$$
\pi^*(s) = \arg\max_{a} \left[ R(s,a) + \gamma \sum_{s'} T(s,a,s') V^*(s') \right]
$$

A política resultante é algo como:

```
→   →   ⊗   ⊗
↑   X   ↑    ←
↑   ↑   ↑   ⊗
```

Onde:

- `→`, `↑`, `←` são ações,  
- `⊗` são estados terminais.

Essa política:

- leva ao +1 rapidamente,  
- evita o −1,  
- contorna paredes,  
- maximiza o valor esperado.

---

## 7. Intuição final

A professora enfatiza:

> Value Iteration não “planeja” explicitamente.  
> Ele simplesmente aplica Bellman repetidamente.  
> A política ótima emerge naturalmente dos valores ótimos.

Ou seja:

- primeiro aprendemos **valores**,  
- depois derivamos **ações**.

---

## 8. Conclusão da Parte 4

Nesta parte aprendemos:

- como Value Iteration funciona na prática,  
- como valores se propagam pelo grid,  
- como a convergência ocorre,  
- como a política ótima é extraída,  
- como Bellman se manifesta visualmente.

Na próxima parte estudaremos:

- variações do algoritmo,  
- considerações práticas,  
- e como Value Iteration se conecta ao RL completo.

Lecture 18 — Parte 5  
Considerações Práticas, Variações e Conexões com RL Completo  
=============================

Nesta parte, concluímos a Lecture 18 discutindo aspectos práticos do Value Iteration, suas variações, limitações e como ele se conecta ao aprendizado por reforço completo (que será o foco da Lecture 19).

O objetivo desta parte é entender:

1. Quando Value Iteration é eficiente,  
2. Quando ele se torna caro,  
3. Variações como Policy Iteration e Modified Policy Iteration,  
4. Como Value Iteration se relaciona com Q-Learning,  
5. Como MDPs resolvidos por Value Iteration se conectam ao RL real.

---

## 1. Considerações práticas sobre Value Iteration

Value Iteration é simples e poderoso, mas possui limitações práticas:

### 1.1 Escalabilidade
Em ambientes pequenos (como grids), Value Iteration é extremamente eficiente.

Mas em ambientes grandes:

- número de estados cresce exponencialmente,  
- número de ações pode ser grande,  
- transições podem ser complexas,  
- a atualização Bellman se torna cara.

### 1.2 Custo computacional
Cada iteração exige:

- varrer todos os estados,  
- testar todas as ações,  
- somar probabilidades de transição,  
- calcular valores futuros.

Isso pode ser caro quando:

- $ |S| $ é grande,  
- $ |A| $ é grande,  
- $ T(s,a,s') $ é complexo.

---

## 2. Variações do algoritmo

A professora menciona que Value Iteration não é o único método para resolver MDPs.

### 2.1 Policy Iteration

Policy Iteration alterna entre:

1. **Avaliação da política**  
2. **Melhoria da política**

Ele é muitas vezes mais rápido que Value Iteration quando:

- o número de ações é pequeno,  
- a política converge rapidamente.

### 2.2 Modified Policy Iteration

Combina:

- a precisão da Policy Iteration,  
- com a velocidade do Value Iteration.

É usado em muitos sistemas práticos.

---

## 3. Conexão com RL completo

Até agora, estamos resolvendo MDPs **com transições e recompensas conhecidas**.

Mas no RL real:

- o agente **não conhece** $ T(s,a,s') $,  
- o agente **não conhece** $ R(s,a,s') $,  
- o agente deve **explorar o ambiente**,  
- o agente deve **aprender a partir de experiência**.

Value Iteration é a base teórica para:

### 3.1 Q-Learning  
Que substitui:

- valores de estado $ V(s) $  
por  
- valores de estado-ação $ Q(s,a) $

E aprende diretamente da experiência.

### 3.2 SARSA  
Que aprende valores seguindo a política atual.

### 3.3 Deep Q-Learning  
Que usa redes neurais para aproximar $ Q(s,a) $.

---

## 4. Por que estudar Value Iteration antes de RL?

Porque Value Iteration:

- ensina a estrutura matemática do problema,  
- mostra como Bellman funciona,  
- explica como valores são propagados,  
- mostra como políticas ótimas são derivadas,  
- prepara o terreno para Q-Learning.

Sem Value Iteration:

- Q-Learning pareceria “mágica”,  
- Bellman pareceria arbitrário,  
- RL pareceria heurístico.

Com Value Iteration:

> RL se torna uma extensão natural de MDPs.

---

## 5. Conexão com o projeto da unidade

O projeto final da unidade envolve:

- um agente que joga jogos baseados em texto,  
- aprendendo apenas por reforço,  
- sem conhecer transições ou recompensas,  
- usando Q-Learning.

Value Iteration fornece:

- a base teórica,  
- a intuição de Bellman,  
- a estrutura de valores,  
- a lógica de políticas ótimas.

---

## 6. Conclusão da Parte 5

Nesta parte aprendemos:

- limitações práticas do Value Iteration,  
- variações como Policy Iteration e Modified Policy Iteration,  
- como Value Iteration se conecta ao RL completo,  
- como ele fundamenta Q-Learning,  
- como ele prepara o terreno para a Lecture 19.

Com isso, concluímos a Lecture 18.
